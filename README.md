## About

I'm a Computer Science student who thinks in systems — how they scale, fail, and stay maintainable over time.

My foundation is **C++**, which shaped how I think about memory, performance, and precision at a low level. I use **Python** for data analysis, automation, and building machine learning pipelines, and **Go** to build lightweight microservices and event-driven architectures that scale without turning into a maintenance burden.

I'm increasingly focused on **data science** and **machine learning** — turning data into models, and models into systems that actually run in production.

Early in my journey, but disciplined: I study architecture, follow engineering principles, and write code that communicates intent.
